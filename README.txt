This is a private/local working version. It is not published on the internet. The downloadable resume PDF has been removed; the Resume page presents selected professional experience.

MAC: HOW TO VIEW THE WEBSITE
-----------------------------
1. Download and unzip this folder.
2. Open the folder in Finder.
3. Double-click index.html.
4. Chrome/Safari will open the homepage.
5. Click the navigation tabs to move between pages.

HOW TO REPLACE THE PHOTO
------------------------
1. Open the images folder.
2. Replace images/profile.jpg with your preferred photo.
3. Keep the new filename as profile.jpg.
4. Open index.html again or refresh the browser.

The current profile image is a black-and-white crop of the supplied photo. It does
not retouch or alter the face. The crop removes the visible red lanyard/tag area,
which is why the lower part of the original photo is not shown.

HOW TO EDIT CONTENT
